# Textdrop｜文件轉 Markdown

拖放文件，自動辨識格式、顯示處理進度，擷取文字後下載 UTF-8 的 `.md` 檔案。介面為繁體中文。

## 直接使用

下載並以近期版本的 Chrome、Edge 或 Firefox 開啟 `index.html`。所有必要程式、PDF 中文字元對照表與標準字型已內含，無須安裝、API Key 或連接轉檔服務。下載後可離線使用。

1. 將檔案拖入左側虛線區，或點擊選取檔案。
2. 加入後自動逐一處理；可在佇列中查看進度與失敗原因。
3. 點選完成的檔案，在右側檢查文字與提示。
4. 按「下載 .md」，或按「複製」取得完整內容。

原始文件只在目前瀏覽器分頁的記憶體中處理，不會上傳到 GitHub 或其他伺服器。重新整理或關閉分頁會清除佇列與結果。網頁本身上線後，其他電腦可直接開啟網址使用。

## 發佈到 GitHub Pages

這份專案是純靜態網頁，可以直接依照 `Deploy from a branch` 方式發佈，不需要執行建置流程。

1. 在自己的 GitHub 帳號建立 repository，例如 `textdrop-md`。GitHub Free 使用公開 repository 即可啟用 Pages；若要使用私有 repository，請確認自己的方案支援。
2. 將本資料夾的內容上傳至 repository 的 `main` 分支。請確保 `index.html` 位在 repository 根目錄，不要再多包一層資料夾。
3. 開啟 **Settings → Pages**。
4. **Source** 選擇 **Deploy from a branch**。
5. **Branch** 選擇 **main**，資料夾選擇 **/ (root)**，按 **Save**。
6. 等 GitHub 完成發佈，再使用 Pages 頁面顯示的實際網址。若 repository 叫 `textdrop-md`，一般形式是 `https://帳號.github.io/textdrop-md/`；這只是格式範例，不表示網站已經發佈。

不需要把測試文件、私人文章或待轉換文件放進 repository。

官方設定說明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 支援範圍

| 類型 | 擷取內容與限制 |
| --- | --- |
| PDF | 文件文字層；支援多頁與中文。掃描頁、轉外框文字需要先做 OCR。混合文件會提示沒有擷取到文字的頁碼。註解與互動表單欄位不含在內。 |
| DOCX | 正文、基本標題／清單、表格、註腳及章節附註。不保留頁首頁尾、註解、已刪除修訂與圖片。 |
| PPTX | 依簡報頁面順序擷取文字、表格。物件內的閱讀順序可能與畫面不同；不包含講者備忘稿、母片、圖表或圖片內文字。 |
| XLSX | 儲存格值、工作表名稱與一般日期。公式只讀已儲存結果，不執行公式；缺少結果會標記。略過隱藏工作表及隱藏列。 |
| ODT | 文字段落、標題與表格。略過圖片、批註及追蹤修訂內容。 |
| HTML、HTM | 移除腳本、樣式、圖片、嵌入物件及隱藏內容；保留連結文字，去除連結網址。 |
| MD、MARKDOWN | 移除圖片、連結網址、前置中繼資料及多餘的強調格式；文件中引用的程式碼保留為普通文字。 |
| TXT、LOG | 擷取文字。 |
| CSV、TSV | 轉換為文字表格，支援引號、分隔符及跨行欄位。第一列作為表格標題。 |
| JSON、XML | 擷取可讀文字與資料值；XML 不允許 DTD 或外部實體。 |

不支援圖片 OCR、舊版 DOC／XLS／PPT、含巨集的 Office 格式、RTF，以及加密文件。這些檔案會顯示說明，不會產出空白的成功結果。

## 設定與容量

- 首次開啟預設使用深色介面；右上角可切換深色／淺色模式，同一瀏覽器會記住選擇。若瀏覽器禁止本機儲存，仍可在目前分頁切換。切換不會清除檔案佇列或轉換結果。
- 預設保留簡單 Markdown 標題、清單與表格；可在「轉換設定」關閉，改輸出段落文字（副檔名仍為 `.md`）。
- 文字檔預設辨識 UTF-8、UTF-16 與 Big5。其他編碼可能需要手動選擇；若出現亂碼，指定編碼後重新加入。
- 單檔最多 50 MB，佇列最多 20 個檔案，總大小最多 200 MB。
- PDF 最多 1,500 頁，單一表格最多 150 欄／100,000 列，文字輸出最多約 1,200 萬字元。
- 超過 60,000 字元時，頁面只預覽前段；下載與複製仍使用完整內容。
- 檔案容量減少比例不等於 AI token 的節省比例。工具不做摘要、不查證內容，也不會辨識或消除文字裡的提示指令。
- 多欄 PDF、特殊字型、複雜表格與文字方塊仍應對照原稿檢查。日期會轉成標準文字形式，不保留各軟體的全部顯示樣式。

## 開發原始碼（選用）

直接使用或發佈時無須這些步驟。若要修改，主要檔案在 `src/`：

- `template.html`：頁面結構。
- `style.css`：樣式。
- `converter.js`：擷取與清理。
- `app.js`：拖放、佇列、預覽及下載。

安裝 Node.js 與 Python 3 後，在專案目錄執行 `npm install`，再執行 `npm run build`。建置會更新根目錄及 `dist/` 的完整 HTML。Windows 若無 `python3` 指令，可執行 `python scripts/build-offline.py`。

PDF.js 與 JSZip 的版本固定於 `package.json`；第三方授權詳見 `LICENSES.txt`，完整 HTML 也內含授權文字。
